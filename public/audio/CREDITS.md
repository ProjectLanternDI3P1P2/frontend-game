# Audio credits

ADR-FE-016: every file served from `public/audio/` is **CC0** or generated by the
squad. A file is merged only once its row is filled in here and the owning squad
has validated it by ear.

Files are named without extension in `app/features/dungeon/audio/dungeonCues.ts`;
each exists as `.webm` (Opus) and `.m4a` (AAC).

## Why two formats

Each sound is stored twice, but **a browser only ever downloads one of them**.

- **`.webm` (Opus) is the main format.** It is the lightest for the same
  quality: every v1 effect together weighs about 70 KB. Chrome, Firefox, Edge
  and recent Safari versions play it.
- **`.m4a` (AAC) is the fallback.** Older Safari versions, on iPhone and iPad
  especially, do not decode Opus reliably, while every browser plays AAC.
  Without it, those players would hear nothing.
- **The choice is automatic.** On start, `AudioEngine` asks the browser
  whether it can play Opus (`canPlayType`): if so it fetches only the `.webm`
  files, otherwise only the `.m4a` files.

The only cost is extra weight in the repository, never for players. The
`.m4a` files can be dropped once every target browser plays Opus.
