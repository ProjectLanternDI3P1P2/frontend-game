## Décisions prises en cours de route
- **`aria-current="true"` sur une seule ligne** (celle visée par « Jump to my rank », sinon `me[0]` ou mon premier héros sur la page). Le badge « You » et le surlignage sont sur tous mes héros. La fiche se contredisait : CA6 met `aria-current` sur tous mes héros, les points F00 et D9 le réservent à une ligne. J'ai suivi F00 et D9.
- **« <previous season> final board »** : le contrat ne permet pas de lire une saison passée. L'action bascule la période sur All time, qui contient les saisons passées. Elle est toujours affichée quand `previousSeasonId` existe ; elle est désactivée, avec l'explication « Already showing the all-time board » (`aria-describedby`), si la période est déjà All time. Le libellé de saison est déduit de l'id (`season-3` → « Season 3 »).
- **Séparateur « N positions between rank X and yours »** : il est placé juste avant le héros qu'il compte. Mes héros mieux classés que la page sont épinglés au-dessus, sans séparateur. Il n'est affiché qu'en tri Total XP, car avec un autre tri les rangs de la page ne sont pas contigus.
- **« Jump to my rank »** remet le tri sur Total XP et garde la classe, la période et la recherche. Avec un filtre (le rang n'est pas renuméroté, D14), la page est trouvée par dichotomie sur `getRanking`.
- **Médailles du podium** : pastille `role="img"` avec `aria-label` « Gold/Silver/Bronze medal », numéro de rang conservé en texte. Les tests F00 et F01 imposent que la cellule Rank contienne exactement le numéro.
- **Badge « XP pending »** sur toute ligne `isPending`, quel que soit le statut.
- **`F00AcceptanceTest.spec.ts`** (hors fichiers possédés) : une ligne modifiée, « Refresh » → « Refresh view », libellé imposé par CA9.
- `DEMO_PLAYER_NAME` est dupliqué dans `rankingViewRules.ts`, car l'import de `mocks/` est interdit.
